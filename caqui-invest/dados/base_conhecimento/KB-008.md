# Como acompanhar um resgate

No app, em **Extrato > Movimentações**, cada pedido mostra o status:

- **Pendente:** pedido registrado, aguardando a data de liquidação.
- **Em processamento:** liquidação acontecendo hoje.
- **Liquidada:** dinheiro na conta Caqui.
- **Recusada:** o pedido não pôde ser feito. O motivo aparece no detalhe.

Se a data prevista passou e o status não mudou, fale com o atendimento.

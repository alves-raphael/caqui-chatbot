# LCI e LCA

LCI e LCA são títulos isentos de imposto de renda para pessoa física.

- **LCI Caqui 92:** carência de 90 dias. Antes disso, o resgate é recusado. Depois, liquidez diária.
- **LCA Caqui 1 ano:** sem liquidez diária. Resgate só no vencimento.

# Imposto de renda na renda fixa

O imposto incide só sobre o **rendimento**, nunca sobre o valor aplicado. A alíquota cai com o tempo de aplicação, contado em dias corridos:

| Prazo             | Alíquota |
| ----------------- | -------- |
| Até 180 dias      | 22,5%    |
| De 181 a 360 dias | 20%      |
| De 361 a 720 dias | 17,5%    |
| Acima de 720 dias | 15%      |

O imposto é retido automaticamente no resgate. IOF não é tratado neste material.
